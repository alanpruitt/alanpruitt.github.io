Section 1 • ~30% of Exam
Fundamentals of Generative AI

Core AI/ML/DL hierarchy, foundation model mechanics, C-S-D-A business value archetypes, learning paradigms, data readiness, and the 4-stage ML lifecycle.

Concentric AI Hierarchy

AI (broadest human-like machine intelligence) → ML (learning patterns from data without explicit rules) → Deep Learning (multi-layer neural networks) → Foundation Models (pre-trained on massive unlabeled data, adaptable to many tasks) → Generative AI (creates new text, code, images, audio, video).

Four Primary Gen AI Use Archetypes (C-S-D-A)

Create (draft emails in Gmail, visuals in Slides/Nano Banana, videos in Google Vids, code in Code Assist) • Summarize (reports in Gemini Notebook, meetings in Meet, reviews in Looker) • Discover (demand forecasting on Agent Platform, recommendations in Agent Search, cross-silo search in Gemini Enterprise) • Automate (Document AI extraction, Speech/Translation APIs).

Three ML Learning Paradigms

Supervised Learning = labeled data (tags/targets known, e.g., spam detection, price prediction). Unsupervised Learning = unlabeled data (finds natural clusters, segments, or anomalies). Reinforcement Learning = learns via rewards & penalties through interaction (includes RLHF used to align LLMs).

Data Readiness & 4-Stage ML Lifecycle

Structured data (SQL/tabular rows) vs. Unstructured data (PDFs, audio, video, emails — ~80%+ of org data). Requires Quality Data (accurate, complete, consistent, relevant) + Accessible Data. Lifecycle: 1. Data Ingestion & Prep → 2. Model Training → 3. Model Deployment → 4. Model Management (Registry versioning + Drift Monitoring).

Model Ecosystem Spectrum

Gemini (Pro / Frontier = deep multi-step reasoning, autonomous agents, up to 1M tokens; Flash = fast multimodal workhorse & Live streaming; Flash-Lite = ultra-low-cost high-volume routing/extraction; Nano = offline on-device edge via LiteRT) • Specialized Google Models (Nano Banana 2.1 / Imagen = conversational image gen & multi-image fusion; Veo 3.1 = video; Lyria = music/audio; Chirp = 100+ lang speech; Text & Multimodal Embeddings = RAG vectors) • Gemma Open-Weights (Gemma 1/2 = English-only; Gemma 3/3n/4 = 140+ languages; ShieldGemma 2 = safety moderation; CodeGemma, PaliGemma, MedGemma) • Partner/OSS in Model Garden.

Exam Watchout: Do not confuse Predictive/Discriminative ML (forecasting numbers, counting visitors, classifying spam) with Generative AI (creating novel text, code, images, audio, or synthetic summaries).

Anatomy & Taxonomy of AI Agents

Every Gen AI Agent combines 3 core parts: 1. Foundation Model ('brain'), 2. Reasoning Loop (observe → interpret → reason → act), and 3. Tools (Extensions for external APIs, Functions for defined actions, Data Stores for RAG knowledge, Plugins). Agent types: Deterministic (strict scripted rules), Generative (natural LLM conversation), Hybrid (best of both: strict transaction guardrails + natural dialogue), and Multi-Agent Systems (specialized agents collaborating on complex goals).

Section 3 • ~20% of Exam
Techniques to Improve Gen AI Model Output

Overcoming knowledge cutoffs, hallucinations, and bias using the cost-aware escalation ladder: Prompting → Grounding → RAG → Fine-Tuning → HITL.

Six Foundation Model Limitations

1. Knowledge Cutoff (frozen at training date) • 2. Hallucinations (plausible fabrications) • 3. Data Dependency & Bias (amplifies training corpus flaws) • 4. No Private Enterprise Context • 5. Finite Context Window (token ceiling) • 6. Edge Cases (rare/atypical inputs).

RAG vs. Fine-Tuning vs. Grounding (Canonical Distinction)

Grounding is the overarching goal of connecting model outputs to verifiable truth. RAG (Retrieve → Augment prompt → Generate → optional Iterate) uses Semantic Search + Vector Databases / Data Stores to ground answers in dynamic private/live docs WITHOUT retraining weights. Fine-Tuning updates model weights on curated labeled datasets to teach specialized domain style, tone, or narrow task behavior.

Prompt Engineering Toolkit

Workspace P-T-C-F Framework (Persona + Task [mandatory action verb] + Context [@file grounding] + Format, ~21+ words + iterative follow-ups) • Zero-shot (0 examples), One-shot (1 example), Few-shot (multiple examples enforcing format/pattern) • Role Prompting • Prompt Chaining • Chain-of-Thought / CoT • ReAct (Reason + Act with tools) • Metaprompting (using AI to write/refine system prompts).

Sampling & Run Parameters

Temperature: Low (0.0–0.2) = deterministic, factual, consistent (use for RAG, code, extraction); High (0.7–1.0) = creative brainstorming • Top-P (Nucleus Sampling): cumulative token probability cutoff • Output Length: max token cap • Safety Settings: configurable harm filters.

Human-in-the-Loop (HITL) Governance

Mandatory human expert oversight in high-risk workflows (healthcare, finance, legal, contextual content moderation) via Pre-generation review (validating before deployment/release) and Post-generation review (continuous feedback loops).

Exam Watchout: Never pick Fine-Tuning when a company's primary need is answering questions from frequently updated manuals, inventory, or policies while minimizing hallucinations — that is ALWAYS Grounding / RAG.
Section 4 • ~15% of Exam
Business Strategies for a Successful Gen AI Solution

Pre-project scoping (6 Needs + 3 Resources), multi-directional change management, KPI measurement, and Google's Secure AI Framework (SAIF).

Pre-Project Scoping: 6 Needs & 3 Resources

6 Needs: Scale (user volume), Customization (SaaS vs. RAG vs. custom), User Interaction, Privacy (PII/PHI sensitivity), Latency (real-time vs. batch), and Connectivity (cloud vs. offline edge). 3 Resources: People (in-house ML skill), Money (budget/TCO), and Time (speed-to-market).

Multi-Directional Adoption (Top-Down + Bottom-Up)

Combine Top-Down executive sponsorship (vision, Responsible AI guardrails, data strategy, KPIs) with Bottom-Up employee experimentation (frontline teams identifying real friction points and sharing reusable prompts).

Six Pillars of Gen AI Execution & ROI

1. Strategic Focus (start with high-impact, feasible use cases) • 2. Exploration (safe sandboxes) • 3. Responsible AI • 4. Resourcing (data quality + upskilling) • 5. Impact Measurement (define baseline metrics FIRST, collect data, iterate) • 6. Continuous Improvement (monitor drift via Model Monitoring).

Secure AI Framework (SAIF) & Cloud Security

SAIF mitigates AI-specific risks (prompt injection, data poisoning, model theft, sensitive data leakage). Enforced on Google Cloud via Identity and Access Management (IAM least privilege), Security Command Center (posture visibility), SynthID watermarking, and Google Cloud's enterprise privacy commitment (customer data/prompts are NOT used to train public foundation models).

Exam Watchout: Avoid 'all-at-once' enterprise rollouts or skipping governance for speed. The exam rewards starting with focused, measurable pilot use cases backed by clear baseline KPIs, SAIF security, and Top-Down + Bottom-Up alignment.

Question 1 of 12 • Section 1 • Fundamentals

A skeptic argues that Generative AI is just another name for traditional predictive analytics. Which use case best demonstrates uniquely Generative AI capability?

Generative AI creates novel content (images, text, code, audio, video), whereas forecasting, fraud classification, and traffic counting are predictive/discriminative analytics or standard reporting.
Question 2 of 12 • Section 1 • Fundamentals

Which machine learning paradigm trains a model using raw, untagged customer records to discover natural purchasing clusters without predefined labels?

Unsupervised learning operates on unlabeled data to uncover hidden patterns, groupings, and anomalies. Supervised learning requires labeled targets; RL learns via reward/penalty feedback.
Question 3 of 12 • Section 1 • Fundamentals

A media agency wants to generate short 1080p promotional video clips directly from text storyboards and reference product photos using Google's first-party model family. Which model should they select?

Veo is Google's text-to-video and image-to-video foundation model. Chirp handles speech-to-text, Gemma 2 is an open-weights text/code family, and LiteRT is the on-device edge runtime.

What are the three essential core components of a Generative AI Agent in Google Cloud's architecture?

Per the official GAIL Study Guide, a Gen AI agent consists of: (1) Model ('the brains'), (2) Reasoning Loop (observe, interpret, reason, act), and (3) Tools (Extensions, Functions, Data Stores, Plugins).

Question 9 of 12 • Section 3 • Improve Model Output

An HR chatbot needs to answer employee benefits questions using the company's current 2026 PDF handbook while avoiding hallucinations and avoiding the cost of retraining model weights whenever policies change. Which approach is best?

RAG retrieves relevant passages from an up-to-date external knowledge base (Data Store / Vector DB) and augments the prompt to achieve grounded, cited responses without retraining weights.
Question 10 of 12 • Section 3 • Improve Model Output

A prompt engineer uses Gemini to draft, critique, and optimize the System Instructions prompt that will govern a downstream manufacturing virtual agent. What is this technique called?

Metaprompting uses an AI model to generate, modify, or refine prompts/system instructions for another AI task or agent.
Question 11 of 12 • Section 3 • Improve Model Output

When configuring sampling parameters for a factual compliance Q&A assistant where consistency and minimal randomness are critical, how should Temperature be set?

Lower Temperature values make token selection more deterministic, factual, and consistent; higher values increase randomness and creative variety.
